# 2026-11-19

## 新功能：市场情绪模块（采集 + 展示）
- 数据表 MarketSentimentDailies（每交易日一行，日期唯一），迁移 `20261119091332_AddMarketSentiment`；`BasisDate` 用非空 DateTime（MinValue=无快照），避免 Npgsql 把可空 DateTime 映射成 timestamptz。
- 数据源：
  - 涨跌家数 / 两市成交额：`push2.eastmoney.com/api/qt/ulist.np/get`（secids=1.000001,0.399001；f104/f105/f106 家数，f6 成交额，f124 快照时间戳）。
  - 涨停 / 跌停 / 炸板 / 最高连板：`push2ex.eastmoney.com/getTopicZTPool|DTPool|ZBPool`，必须带 `date=YYYYMMDD`（缺省返回 rc=102）；跌停池必须 `sort=fund:asc`（`fbt:asc` 返回 tc 但 pool 为空）；ZT 池 `lbc` 为连板数。
  - 涨跌分布 / 行业冷暖 / 平均涨跌幅：库内 StockFundamentals 最近一次收盘快照；成交额兜底用 IndexDailies（000001 + 399106 深证综指，不是 399001）。
- 情绪分 0-100：上涨占比 35% + 涨停跌停对比 25% + 连板高度 15%（6 板封顶）+ 封板率 10% + 成交额相对 20 日均值 15%（0.5~1.5 倍截断）。分项缺失时剔除权重再归一化；炸板数据缺失（涨停池不可用）时剔除封板率，不能用 0 代替。
- 交易日归属：先按 f124 定日期再拉涨停池；盘前 9:30 前与周末回退到 IndexDailies 最近交易日，避免把上一交易日口径写成今天、也避免用今天去查涨停池拿到空池覆盖昨收数据。
- 历史不做回补：涨跌家数取不到历史，从上线日起逐日积累。
- 调度：Web Hangfire `sentiment-intraday`（`*/10 9-15 * * 1-5`）+ `sentiment-close`（`25 17 * * 1-5`）；独立 Collector 日任务与盘中 10 分钟循环均已接入；`POST /api/collect/sentiment` 与 `POST /api/sentiment/sync` 可手动触发。
- 前端：/sentiment 页（情绪温度计 + 涨跌家数趋势 + 行业冷暖 + 涨跌分布），顶部菜单「🌡️ 情绪」。
- 情绪日历（SentimentCalendar.vue）：与情绪表盘并排的 300px 紧凑卡片（≤900px 时堆叠），按交易日格子显示 0-100 情绪分，五档冷热配色（冰点灰 / 低迷蓝 / 中性黄 / 活跃橙 / 亢奋红），支持月份翻页（仅往前，最近一年）、悬停查看当日涨跌家数、涨跌停、成交额与连板；趋势图与日历共用一次 `history?days=365` 请求，区间切换改为前端按日期截取。
- 验证：Web/Collector 构建通过，前端 build 通过，xUnit 56 项通过（新增 MarketSentimentTests 覆盖评分归一化/涨跌停阈值/分布分桶）；SQLite 冒烟采集 647 涨 / 4594 跌 / 53 平，涨停 23 / 跌停 68 / 炸板 24 / 最高 3 连板，成交 13051 亿，二次同步仅 1 行。
